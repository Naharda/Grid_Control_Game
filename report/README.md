# Course report (AAAI'27 format)

LaTeX source of the final report, typeset with the official AAAI'27
camera-ready template. The figures and supporting tables are generated by
`analysis/build_course_paper.py`.

- `graph_card_control_report.tex` — the report
- `references.bib` — bibliography (formatted by `aaai2027.bst`)
- `aaai2027.sty` / `aaai2027.bst` — official AAAI'27 style files
- Figures are included from `../final_results/course_paper/figures/` (vector PDFs)

Build:

```bash
cd report
latexmk -pdf graph_card_control_report.tex
```

The compiled PDF is published as `output/pdf/graph_card_control_final_report.pdf`.
